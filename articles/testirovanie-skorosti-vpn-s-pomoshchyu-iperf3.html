Что такое iperf3 и зачем он нужен?

iperf3 — это кроссплатформенный инструмент командной строки для измерения пропускной способности сети. Он создаёт поток данных между клиентом и сервером и измеряет скорость передачи, задержки, потери пакетов и другие параметры. В отличие от обычных speed-тестов (например, Speedtest.net), iperf3 позволяет:

  • Тестировать реальную пропускную способность сети без влияния сторонних серверов.
  • Измерять скорость в обоих направлениях (от клиента к серверу и обратно).
  • Настраивать параметры теста: размер пакетов, количество потоков, время теста.
  • Анализировать потери пакетов и джиттер (особенно важно для UDP).
  • Тестировать конкретный порт, что позволяет проверить именно VPN-туннель.

Для тестирования VPN iperf3 — идеальный выбор, потому что вы можете запустить серверную часть на удалённой машине (например, на вашем VPS) и клиентскую — на своём устройстве, подключённом через VPN. Это даёт объективную картину производительности вашего соединения.

Почему важно тестировать скорость VPN?

Многие пользователи жалуются на низкую скорость VPN, но редко проводят объективные измерения. Без тестов сложно понять:

  • Действительно ли провайдер ограничивает скорость?
  • Не является ли проблема на вашей стороне (Wi-Fi, старый роутер)?
  • Какой протокол даёт лучшую производительность в ваших условиях?
  • Не влияет ли шифрование на пропускную способность?

Регулярное тестирование с помощью iperf3 помогает выявить узкие места и выбрать оптимальные настройки. Особенно это важно для пользователей, которые работают с большими объёмами данных, стримят видео или играют в онлайн-игры.

📊 Что измеряет iperf3:

  • Bandwidth (пропускная способность) — скорость передачи данных в Мбит/с.
  • Retransmissions (переотправки) — количество повторных передач TCP (признак проблем).
  • Jitter (джиттер) — вариация задержки для UDP.
  • Packet loss (потери пакетов) — процент потерянных пакетов.

Установка iperf3 на разные платформы

iperf3 доступен для всех основных операционных систем. Вот как его установить:

🐧 Linux (Ubuntu/Debian):

sudo apt install iperf3

🍎 macOS:

brew install iperf3

🪟 Windows:

Скачайте исполняемый файл с официального сайта или используйте winget install iperf3

📱 Android/iOS:

Существуют сторонние приложения с iperf3 (например, iperf3 для Android).

После установки проверьте, что всё работает: iperf3 -v должен показать версию.

Сценарии тестирования: TCP, UDP, многопоточность

iperf3 поддерживает два основных режима: TCP и UDP. Каждый из них полезен для разных сценариев:

📦 TCP

Использование: веб-сёрфинг, загрузка файлов, email

Особенности: гарантирует доставку, регулирует скорость при потерях

Надёжный

📡 UDP

Использование: стриминг, VoIP, онлайн-игры

Особенности: высокая скорость, возможны потери пакетов

Быстрый

Для тестирования VPN рекомендуется запускать оба режима — так вы получите полную картину. Также полезно использовать параллельные потоки (-P) для имитации многозадачности и измерения максимальной пропускной способности.

Пошаговая инструкция по тестированию VPN

1 Запустите сервер iperf3 на удалённом VPS

Подключитесь к вашему VPS по SSH и выполните: iperf3 -s (сервер будет слушать порт 5201 по умолчанию).

2 Подключитесь к VPN

Убедитесь, что VPN-соединение активно и весь трафик направляется через туннель.

3 Запустите клиент iperf3 на локальной машине

Выполните команду: iperf3 -c <IP_вашего_VPS> для теста TCP. Для UDP добавьте -u, для параллельных потоков -P 4.

4 Проведите несколько тестов

Изменяйте параметры: время (-t), размер окна (-w), направление (-R для обратного). Записывайте результаты.

5 Повторите тест без VPN

Отключите VPN и снова запустите iperf3 на тот же VPS. Сравните результаты — так вы увидите, сколько скорости «съедает» VPN.

Пример команды для теста TCP с 4 потоками в течение 30 секунд:

iperf3 -c 192.168.1.100 -P 4 -t 30

Как интерпретировать результаты iperf3

После завершения теста вы увидите примерно такой вывод:

[SUM]   0.00-30.00  sec  1.58 GBytes   453 Mbits/sec  0.027 ms  0/12500 (0%)

Что означают эти цифры?

  • 453 Mbits/sec — средняя пропускная способность за 30 секунд. Это и есть реальная скорость вашего VPN-канала.
  • 1.58 GBytes — общий объём переданных данных.
  • 0/12500 (0%) — потери пакетов (для UDP) или количество переотправок (для TCP). Ноль — идеальный результат.
  • 0.027 ms — задержка (RTT) в данном сегменте.

Если вы видите значительное снижение скорости при включённом VPN по сравнению с прямым соединением, это может указывать на:

  • Слабый протокол шифрования, нагружающий CPU.
  • Удалённость сервера (большое расстояние увеличивает задержку).
  • Перегруженность общего сервера (характерно для массовых VPN).
  • Ограничения со стороны интернет-провайдера (DPI, throttling).

Влияние XHTTP + Reality на скорость

Технология XHTTP + Reality не только маскирует VPN-трафик под обычный HTTPS, но и имеет минимальный оверхед. В отличие от OpenVPN, который может «съедать» до 20% скорости из-за шифрования и инкапсуляции, XHTTP работает на уровне TLS-сессий, что делает его почти незаметным для производительности.

🔬 Почему XHTTP + Reality быстрее:

  • Имитация TLS-рукопожатия — соединение выглядит как стандартный HTTPS, без дополнительных обёрток.
  • Отсутствие двойного шифрования — в отличие от IPSec или OpenVPN, данные не шифруются дважды.
  • Оптимизированные алгоритмы — используются современные криптографические методы с низким потреблением CPU.
  • Адаптивный размер пакетов — автоматическая настройка MTU для минимизации фрагментации.

В тестах iperf3 соединение с XHTTP + Reality показывает практически ту же скорость, что и прямое подключение к серверу без VPN — разница составляет всего 2–5% (в отличие от 15–30% у старых протоколов). Это делает технологию идеальным выбором для пользователей, которым важна высокая производительность.
