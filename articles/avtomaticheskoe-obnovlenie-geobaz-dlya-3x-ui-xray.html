Автоматическое обновление геобаз для 3x-UI / Xray: полное руководство

Панель 3x-UI и ядро Xray — это мощный тандем для построения современных VPN-серверов с обходом DPI. Однако даже самая продвинутая конфигурация теряет эффективность, если геобазы (GeoIP и GeoSite) устаревают. В этой статье мы разберём, зачем нужно автоматическое обновление геобаз, как его настроить на сервере с 3x-UI и почему это критически важно для стабильной работы вашего личного VPN.

Что такое геобазы и зачем их обновлять

GeoIP — это база данных, сопоставляющая IP-адреса с географическим положением (страна, регион). GeoSite — аналогичная база для доменных имён. В Xray эти базы используются для маршрутизации трафика: например, можно направить все запросы к российским сайтам напрямую, а к зарубежным — через VPN-туннель.

Провайдеры постоянно меняют IP-адреса и доменные зоны. Если геобазы устарели, маршрутизация начинает работать некорректно: трафик может идти не тем путём, что снижает скорость и увеличивает риск обнаружения DPI-системами. Автоматическое обновление геобаз решает эту проблему, поддерживая актуальность данных без вашего участия.

Структура GeoIP и GeoSite в Xray

В Xray геобазы хранятся в файлах geoip.dat и geosite.dat. Они расположены в директории, указанной в конфигурации (обычно /usr/local/share/xray/ или /etc/xray/). Эти файлы имеют специальный бинарный формат и обновляются через официальные репозитории проекта Xray-core.

📂 Где искать геобазы:

  • /usr/local/share/xray/geoip.dat
  • /usr/local/share/xray/geosite.dat
  • Или путь, указанный в config.json через параметры geoipFile и geositeFile.

В 3x-UI пути к геобазам задаются в настройках инбаундов (входящих подключений) или в глобальных настройках панели. Обычно используются стандартные пути, но всегда стоит проверить актуальное расположение.

Ручное обновление геобаз

Прежде чем переходить к автоматизации, разберём ручной способ. Это полезно для понимания процесса и отладки.

# Скачиваем свежие версии geoip.dat и geosite.dat curl -L -o /usr/local/share/xray/geoip.dat https://github.com/v2fly/geoip/releases/latest/download/geoip.dat curl -L -o /usr/local/share/xray/geosite.dat https://github.com/v2fly/geosite/releases/latest/download/geosite.dat # Перезапускаем Xray для применения изменений systemctl restart xray

После перезапуска Xray начнёт использовать обновлённые базы. Однако ручное обновление требует постоянного внимания — гораздо удобнее настроить автоматическое обновление по расписанию.

Автоматизация через cron

Самый надёжный способ автоматического обновления геобаз — использование cron (планировщика задач в Linux). Мы создадим скрипт, который будет скачивать свежие файлы и перезапускать Xray, а затем добавим его в cron для выполнения, например, раз в неделю.

⏱ Рекомендуемая периодичность:

  • GeoIP — обновляется несколько раз в неделю, достаточно запускать обновление раз в 3–5 дней.
  • GeoSite — обновляется реже, можно обновлять раз в неделю.
  • Для максимальной актуальности можно настроить ежедневное обновление — нагрузка на сервер минимальна.

Скрипт для обновления геобаз

Создадим скрипт /usr/local/bin/update-geo.sh со следующим содержимым:

#!/bin/bash # Скрипт автоматического обновления геобаз для Xray GEOIP_URL="https://github.com/v2fly/geoip/releases/latest/download/geoip.dat" GEOSITE_URL="https://github.com/v2fly/geosite/releases/latest/download/geosite.dat" GEO_DIR="/usr/local/share/xray" # Скачиваем новые файлы curl -L -o "$GEO_DIR/geoip.dat.new" "$GEOIP_URL" curl -L -o "$GEO_DIR/geosite.dat.new" "$GEOSITE_URL" # Проверяем, что файлы скачались успешно if [ -f "$GEO_DIR/geoip.dat.new" ] && [ -f "$GEO_DIR/geosite.dat.new" ]; then # Заменяем старые файлы mv "$GEO_DIR/geoip.dat.new" "$GEO_DIR/geoip.dat" mv "$GEO_DIR/geosite.dat.new" "$GEO_DIR/geosite.dat" echo "$(date): Геобазы успешно обновлены" >> /var/log/geo-update.log # Перезапускаем Xray systemctl restart xray else echo "$(date): Ошибка при скачивании геобаз" >> /var/log/geo-update.log fi

Не забудьте сделать скрипт исполняемым: chmod +x /usr/local/bin/update-geo.sh.

Теперь добавим задание в cron (crontab -e):

# Обновление геобаз каждый понедельник в 3:00 0 3 * * 1 /usr/local/bin/update-geo.sh

Интеграция с 3x-UI

Панель 3x-UI удобна тем, что позволяет управлять инбаундами и маршрутизацией через веб-интерфейс. Однако она не предоставляет встроенного механизма обновления геобаз. Поэтому мы используем описанный выше скрипт — он работает независимо от панели и обновляет файлы, которые использует Xray.

Важно: после обновления геобаз Xray должен быть перезапущен. В скрипте мы использовали systemctl restart xray. Если вы используете Docker или другой способ запуска, адаптируйте команду перезапуска.

✅ Проверка обновления в 3x-UI:

После выполнения скрипта зайдите в 3x-UI → вкладка «Xray» → «Конфигурация». Убедитесь, что пути к geoip.dat и geosite.dat указаны верно. Если вы меняли директорию, отредактируйте переменную GEO_DIR в скрипте.
