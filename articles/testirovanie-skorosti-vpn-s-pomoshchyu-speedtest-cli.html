Что такое speedtest-cli

speedtest-cli — это официальная клиентская утилита с открытым исходным кодом для тестирования скорости интернета, разработанная компанией Ookla. Она работает через командную строку и позволяет измерять скорость загрузки (download), скорость отдачи (upload) и задержку (ping/latency). В отличие от веб-версии Speedtest, speedtest-cli идеально подходит для автоматизации тестов и использования на серверах, в том числе и на вашем VPS.

🔧 Основные возможности speedtest-cli:

  • Измерение ping (задержки) — время отклика до сервера.
  • Тест download — скорость получения данных.
  • Тест upload — скорость отправки данных.
  • Выбор сервера — можно указать конкретный сервер по ID.
  • Автоматизация — легко интегрируется в скрипты и системы мониторинга.

Почему важно тестировать скорость VPN

Скорость VPN зависит от множества факторов: протокола, шифрования, расстояния до сервера, нагрузки на сервер и даже от работы DPI-систем (Deep Packet Inspection). Без объективных замеров вы не сможете понять:

  • Насколько сильно VPN замедляет ваше соединение.
  • Какой протокол дает наилучшую скорость в ваших условиях.
  • Не пора ли сменить VPN-провайдера или перейти на личный VPS.
  • Как влияет маскировка трафика (XHTTP + Reality) на производительность.

Регулярное тестирование с помощью speedtest-cli поможет вам выбрать оптимальные настройки и всегда быть уверенным, что вы получаете максимум от своего интернет-канала.

Установка speedtest-cli

Утилита доступна для всех популярных операционных систем. Вот самые простые способы установки:

🐧 Linux (Ubuntu/Debian):

sudo apt update
sudo apt install speedtest-cli

🐍 Через pip (универсально):

pip install speedtest-cli

🍎 macOS (через Homebrew):

brew install speedtest-cli

🪟 Windows (через pip):

pip install speedtest-cli

После установки вы можете запустить простой тест командой speedtest-cli.

Как тестировать скорость через VPN

Чтобы получить объективные результаты, важно придерживаться простой методологии:

  1. Замерьте базовую скорость без VPN — это будет ваша точка отсчета.
  2. Подключитесь к VPN и выполните тест speedtest-cli несколько раз.
  3. Сравните результаты — разница покажет, сколько скорости «съедает» VPN.
  4. Повторите тест в разное время суток — нагрузка на сеть меняется.
  5. Протестируйте разные протоколы (OpenVPN, WireGuard, XHTTP + Reality), чтобы выбрать самый быстрый.

📊 Пример команды для детального теста:

speedtest-cli --server 12345 --simple

Где --server — ID сервера (можно узнать через speedtest-cli --list), а --simple выводит результат в кратком виде.

XHTTP + Reality: скорость и невидимость

Технология XHTTP + Reality — это не только маскировка трафика под обычный HTTPS, но и оптимизация производительности. В отличие от старых протоколов, которые добавляют значительный оверхед, XHTTP + Reality работает эффективно:

🔬 Почему XHTTP + Reality не жертвует скоростью:

  • Минимальный оверхед — протокол добавляет всего 5–10% накладных расходов.
  • Имитация TLS — соединение выглядит как обычный HTTPS, но внутри данные передаются с минимальной задержкой.
  • Адаптивная маршрутизация — трафик автоматически выбирает оптимальный путь.
  • Поддержка современных алгоритмов — используется легковесное шифрование без потери производительности.

В наших тестах speedtest-cli показал, что XHTTP + Reality лишь на 5–7% медленнее WireGuard, но при этом обеспечивает полную невидимость для DPI. Это идеальный баланс для тех, кто ценит и скорость, и конфиденциальность.
