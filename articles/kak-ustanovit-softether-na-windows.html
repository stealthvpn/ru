Что такое SoftEther VPN?

SoftEther VPN (Software Ethernet) — это бесплатный VPN-сервер с открытым исходным кодом, разработанный в Университете Цукуба (Япония). Он поддерживает множество протоколов, что позволяет подключаться к нему с практически любого устройства: Windows, macOS, Linux, Android, iOS и даже маршрутизаторов.

Главная особенность SoftEther — его способность маскировать VPN-трафик под HTTPS, что помогает обходить DPI (Deep Packet Inspection) и блокировки. Кроме того, он поддерживает кластеризацию и балансировку нагрузки, что делает его популярным выбором для корпоративных сетей.

Почему SoftEther — отличный выбор

  • Мультипротокольность — поддерживает OpenVPN, L2TP/IPsec, SSTP, EtherIP и собственный протокол.
  • Простота настройки — удобный графический интерфейс и мастер установки.
  • Высокая производительность — оптимизирован для работы на Windows и Linux.
  • Обход DPI — может маскировать трафик под HTTPS, что помогает обходить блокировки.
  • Бесплатность — полностью открытый код, можно использовать без ограничений.

Пошаговая установка SoftEther на Windows

Шаг 1.

Скачайте установочный файл

Перейдите на официальный сайт SoftEther VPN (softether.org) и скачайте последнюю версию для Windows. Обратите внимание, что есть две версии: SoftEther VPN Server (для создания сервера) и SoftEther VPN Client (для подключения к серверу). Нам нужен сервер.

Шаг 2.

Запустите установщик

Запустите скачанный файл softether-vpnserver-vpnbridge-x.x.x-xxxx-xxx.exe. В появившемся окне выберите язык (по умолчанию — английский) и нажмите Next.

Шаг 3.

Примите лицензионное соглашение

Ознакомьтесь с лицензией GPLv2 и нажмите I agree.

Шаг 4.

Выберите компоненты для установки

Убедитесь, что выбран SoftEther VPN Server. Также можно установить VPN Bridge и VPN Client, но для сервера достаточно первого пункта. Нажмите Next.

Шаг 5.

Выберите папку установки

Оставьте путь по умолчанию (C:\Program Files\SoftEther VPN Server) или выберите свою папку. Нажмите Next.

Шаг 6.

Настройка брандмауэра

Установщик предложит открыть порты в брандмауэре Windows. Рекомендуется согласиться, чтобы к серверу можно было подключаться извне. Нажмите Next.

Шаг 7.

Завершение установки

Нажмите Install и дождитесь окончания установки. После завершения установщик предложит запустить SoftEther VPN Server Manager — согласитесь, чтобы сразу перейти к настройке.

Первоначальная настройка сервера

После установки откроется SoftEther VPN Server Manager. Это графический интерфейс для управления сервером.

Шаг 1.

Подключитесь к локальному серверу

В менеджере нажмите Connect. В поле Hostname укажите localhost, порт оставьте 443 (или 5555, если используете другой). Нажмите Connect.

Шаг 2.

Установите пароль администратора

При первом подключении программа попросит установить пароль для администратора. Придумайте надёжный пароль и запомните его.

Шаг 3.

Запустите мастер настройки

После установки пароля откроется мастер настройки. Выберите Создать новый VPN-сервер и следуйте инструкциям.

Создание пользователя и подключение

Шаг 1.

Создайте виртуальный хаб

В менеджере перейдите на вкладку Virtual Hub и нажмите Create Virtual Hub. Введите имя (например, VPN) и нажмите OK.

Шаг 2.

Добавьте пользователя

В созданном хабе перейдите на вкладку Users и нажмите Create User. Заполните поля:

  • User Name — логин (например, user1)
  • Password — пароль для подключения
  • Остальные поля можно оставить по умолчанию

Нажмите OK.

Шаг 3.

Настройте протоколы доступа

Перейдите на вкладку VPN Protocols и включите нужные протоколы (L2TP, OpenVPN, SSTP и т.д.). Для каждого протокола можно настроить порты и параметры шифрования.

Шаг 4.

Подключитесь к серверу

Теперь вы можете подключиться к своему VPN-серверу с любого устройства, используя один из поддерживаемых протоколов. Например, на Windows можно настроить встроенное VPN-подключение через L2TP/IPsec или SSTP.

Важно: Если вы используете SoftEther на домашнем компьютере, убедитесь, что порты (по умолчанию 443, 5555, 500, 4500) открыты в вашем роутере и проброшены на локальный IP-адрес компьютера.

XHTTP + Reality — технология будущего

🔬 Что такое XHTTP + Reality?

Это технология маскировки VPN-трафика под обычный HTTPS-запрос к легитимному сайту. DPI не может отличить ваше соединение от реального браузера Chrome, потому что:

  • Имитация TLS-рукопожатия — соединение выглядит как стандартный HTTPS-запрос.
  • Маскировка под Chrome — все параметры соответствуют реальному браузеру (версия, набор шифров, заголовки).
  • Отсутствие характерных сигнатур — в отличие от OpenVPN или WireGuard, у XHTTP нет узнаваемых паттернов.
  • Динамическая адаптация — трафик меняется в зависимости от контекста.

Благодаря этой технологии ваш VPN-трафик неотличим от обычного веб-сёрфинга. Это делает XHTTP + Reality идеальным решением для стран с жёсткой фильтрацией интернета и активным DPI.
